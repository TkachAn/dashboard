Концепция умного дома: Архитектура и автоматизация
1. Аппаратный фундамент и роли устройств
* ТВ-приставка (Linux): Главный сервер умного дома (узел управления, MQTT-брокер, веб-интерфейс). Работает в тихом режиме без лишней периферии.
* Orange Pi: Аппаратный хаб продвинутых датчиков и прямых исполнительных узлов (свободная гребенка GPIO для локальной автоматики).
* Расположение узлов ESP8266 с датчиками BME280:
   * Внешние узлы: юго-восточная и северо-западная стороны дома (измерение внешней температуры, влажности, давления и градиентов между сторонами).
   * Внутренние узлы: спальня, зал, мастерская, кухня, ванна.
* Мультисенсоры и пульты управления:
   * BroadLink RM pro+: Универсальный пульт для управления кондиционером по ИК-каналу, а также освещением и розетками по радиоканалу (RF 433/315 МГц).
   * Дополнительный сенсор BroadLink (расположен в общем коридоре, который имеет непосредственную связь со всеми комнатами: залом, спальней, офисом, а также с другим коридором, который, в свою очередь, связан с прихожей, ванной, туалетом, кухней и тем же общим коридором): Измерение температуры, влажности, качества/частоты воздуха, давления и уровня шума в центральной проходной зоне.
* Помещения с приводами заслонок:
   * Зал
   * Спальня
   * Ванна и туалет (моторизованная заслонка на общий вытяжной канал для предотвращения избыточного выдувания тепла зимой)
* Помещения и зоны с вентиляторами и вытяжками:
   * Кухня (кухонная вытяжка)
   * Общий принудительный вентилятор системы воздухообмена
* Вентиляционные шахты и каналы:
   * Кухня: 2 шахты (одна приточная, одна вытяжная) плюс отдельный канал (сквозь стену) кухонной вытяжки.
   * Ванна и туалет: 1 общий канал вытяжки на оба помещения (с регулируемой заслонкой).
* Монитор энергопотребления (поветвевой) в электрическом щитке: Отслеживание активной бытовой техники (такой как стиральная и бойлер).
* Универсальный шлюз (RS-485 / Wi-Fi): Управление кондиционером (порт Link), светом и радиопередатчиками на большие расстояния.
* Роутер с внешним диском: Подмонтированная сетевая папка (Samba/NFS) для хранения базы данных SQLite, что полностью защищает eMMC/SD-память приставки от износа при частых записях.
* 2. Программный стек сервера на приставке
* Node.js + Next.js: Основной веб-дашборд, API-роуты и серверная логика принятия решений.
* PM2: Менеджер процессов для автозапуска и постоянной работы приложения.
* Mosquitto MQTT (напрямую в Linux): Легковесный брокер сообщений на порту 1883 без использования Docker для максимальной экономии ресурсов.
* SQLite (better-sqlite3): База данных на внешнем сетевом диске для хранения истории климата и энергопотребления.
* GitHub Автодеплой: Обновление кода на приставке в один git push (разработка на ПК, сборка и обновление на сервере).
* broadlink / broadlinkjs-mqtt: Библиотеки для прямого локального управления устройствами BroadLink без использования облачных сервисов.
3. Логика работы заслонок и климат-контроля
* Четыре оконных узла (северная, западная, восточная стороны и помещения) передают текущие параметры через MQTT.
* Сравнение температуры на улице и в комнатах позволяет открывать нужные заслонки для создания регулируемого естественного сквозняка и выравнивания температуры.
* Интеграция с кондиционером: подключение принудительного охлаждения через шлюз только тогда, когда естественная вентиляция не справляется.
* Поветвенный мониторинг энергопотребления в электрощитке для точного определения рабочих циклов техники и автоматизации превентивных систем.
4. Перспектива: ИИ-анализатор
* Накопление интервальных показаний в SQLite (редкие срезы для климата, подробный сбор данных по энергопотреблению).
* Интеграция легкой локальной модели искусственного интеллекта, которая обучается на накопленных данных и оптимизирует работу узлов в предиктивном режиме.
5. Инновационная защита от протечек (Превентивная система)
* Концепция 'закрыто по умолчанию': Запорный сервопривод/электрокран на стояке перекрывает воду, когда в помещении нет активности, предотвращая аварии до их возникновения.
* Логика открывания: Подача воды включается по датчикам движения на кухне/в ванной.
* Задержка закрытия: Кран остается открытым еще в течение 30-60 минут после последнего зафиксированного движения, чтобы не создавать неудобств.
* Отслеживание бытовой техники: Для стиральной и посудомоечной машин подача воды удерживается открытой на основе мониторинга их энергопотребления по веткам в электрощитке.
